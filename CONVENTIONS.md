# Conventions

## Research Before Implementing

Before writing unfamiliar code from scratch, search GitHub, GitLab, Gitea, Codeberg, Bitbucket, SourceForge, AWS CodeConnections, Gist, and package registries. Accept only maintained (<6mo commits), clearly licensed, genuinely used projects (not just stars), with reviewed dependencies. Adapt, don't copy. If nothing fits, explain why, then implement from scratch. Report sources and rationale briefly.
